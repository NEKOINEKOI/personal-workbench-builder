# 运行环境能力检查

开发前必须检查当前环境。

```yaml
environment_capabilities:
  available: []
  unavailable: []
  needs_user_setup: []
  alternative_plan: []
```

## 检查项目

### 文件

- 能否读取本地文件
- 能否写入本地文件
- 能否长期保存生成文件

### 代码

- 能否执行代码
- 支持哪些语言
- 能否安装依赖
- 能否启动本地服务

### 网络

- 能否访问互联网
- 能否请求 API
- 是否有域名或来源限制

### 数据

- 是否支持数据库
- 是否支持本地持久化
- 是否支持云端保存
- 是否支持多设备同步

### 外部连接

- 是否有邮箱连接器
- 是否有日历连接器
- 是否有云盘连接器
- 是否有第三方平台连接器

### 自动化

- 是否支持定时任务
- 最短执行频率
- 是否支持后台运行
- 失败后是否有通知

### 部署

- 能否部署网页
- 能否生成本地应用
- 能否生成可执行文件
- 是否需要用户自行部署

## 处理规则

- 环境不支持时，不得承诺已实现。
- 优先提供替代方案。
- 需要用户配置时，明确列出步骤。
- 无法长期运行的环境，不得描述为后台自动化。
