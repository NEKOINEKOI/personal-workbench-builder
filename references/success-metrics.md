# 成功指标

需求阶段至少确定以下指标。

```yaml
success_metrics:
  weekly_active_days:
  core_workflow_completions:
  expected_time_saved_per_week:
  expected_reduction:
  unused_feature_review_after_days: 14
  review_frequency: monthly
```

## 指标解释

### 每周活跃天数

用户预计一周打开几天。

### 关键任务完成次数

用户一周通过工作台完整完成多少次核心任务。

### 每周节省时间

估算减少多少重复操作、搜索和软件切换。

### 减少遗漏

可以记录：

- 少忘记几次
- 少漏回复几次
- 少重复录入几次
- 少切换几个工具

### 未使用功能检查

默认：

- 连续 14 天未使用，进入删除候选
- 每月检查一次第一版模块
- 无法证明价值的模块优先删除

## 原则

工作台的目标不是功能多，而是：

- 用户会打开
- 关键任务能完成
- 确实减少麻烦
- 长期不用的功能会被删掉
